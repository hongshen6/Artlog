# Security Policy

## Reporting a vulnerability

If you find a security issue in Artlog, please report it privately to the
author at **3569694301@qq.com** instead of opening a public Issue.

Please include:

- a description of the issue and its impact;
- steps to reproduce it;
- the app version and your device / Android version.

Please do not publicly disclose the details until the author has had a
reasonable time to address the issue.

## Scope

Artlog is a local-first, fully offline app: it has no accounts, no
servers, and no network uploads. The most relevant risks are local data
handling (backups, file imports) and Android permissions. Reports about
the app's own code are welcome; reports about third-party websites linked
from the visual inspiration directory should go to those sites.
